# Jairo Cavalcante Ávila — Website profissional

Website institucional do psicanalista clínico Jairo Cavalcante Ávila, desenvolvido pela **Threeebs!**.

O projeto apresenta a trajetória profissional e acadêmica, informações sobre atendimento em psicanálise clínica, perguntas frequentes e contato para agendamento.

## Tecnologias

- HTML5 sem framework
- CSS3 responsivo, com temas claro e escuro
- JavaScript nativo
- Fontes **Playfair Display** e **DM Sans** (Google Fonts)

## Estrutura

```text
public/
├── index.html
├── pages/
│   └── sobre/index.html
└── assets/
    ├── css/styles.css
    ├── js/script.js
    └── images/
        ├── jairo-cavalcante.png
        └── favicon.svg
```

## Como executar

Abra `public/index.html` em um navegador ou sirva a pasta `public` com um servidor HTTP estático:

```bash
python3 -m http.server 8080 --directory public
```

Acesse `http://localhost:8080`. Não há etapa de instalação ou compilação.

## Identidade visual

Paleta em vinho, bordô, bege, off-white e dourado, mantendo uma apresentação acolhedora, sóbria e profissional. Layout responsivo, com animações discretas e suporte a `prefers-reduced-motion`.

## Imagens e compartilhamento

O retrato principal fica em `public/assets/images/jairo-cavalcante.png`. A prévia para compartilhamento pode ser personalizada com imagem **Open Graph** 1200 × 630, configurada em `public/index.html` após disponibilizar o arquivo no repositório.
